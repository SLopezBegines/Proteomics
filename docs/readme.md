# Output Reference — Proteomics Pipeline

This document describes all files generated by the pipeline under `output/{analysis_name}/`.
Every analysis run creates its own named subdirectory (set via `output_path` in the main `.Rmd`),
keeping results from different experiments cleanly separated.

---

## Output Directory Structure

```
output/{analysis_name}/
├── tables/          # Excel spreadsheets with processed data and statistical results
├── figures/         # Main analysis figures (TIFF + PDF)
│   ├── enrichGO/    # Gene Ontology over-representation analysis plots
│   ├── gseGO/       # GO gene set enrichment analysis (GSEA) plots
│   ├── KEGG/        # KEGG pathway enrichment plots
│   ├── KEGG_GO/     # Combined KEGG + GO plots
│   ├── panther/     # PANTHER pathway analysis figures (via rbioapi)
│   └── rbioapi/     # STRING protein network images (downloaded programmatically)
├── RData/           # R workspace snapshots for downstream reuse
└── VennDiagram/     # Venn diagrams of overlapping protein sets across comparisons
```

All figures are saved in dual format:
- **`.pdf`** — vector format, recommended for editing and publication
- **`.tiff`** — raster format at publication quality (300 dpi, 8 × 6 in unless noted)

Figure filenames follow the pattern `{image_number}_{description}.pdf/.tiff`, where `image_number`
is a sequential counter initialised at `1` in the main `.Rmd`.

## Tables (`tables/`)

| File | Description |
|------|-------------|
| `experiment_design.xlsx` | Experimental design matrix: sample names, conditions, and replicates as defined in the `.Rmd` setup section. |
| `prot_data_cleaned_data.xlsx` | Raw data after initial processing: contaminants and non-informative rows removed, column names standardised. |
| `prot_data_contaminants.xlsx` | Proteins flagged as contaminants and excluded from analysis. Useful for audit and inspection. |
| `prot_data_selected_data.xlsx` | Subset of cleaned data retained for downstream analysis after all filtering steps. |
| `dep_imputed_prots_prot_data.xlsx` | Per-imputation-method count of proteins with adjusted p-value below threshold. Includes the manual value used for mixed imputation. |
| `data_results.xlsx` | Master results table: all processed data including statistical test outputs and imputed values for every protein across all comparisons. Primary reference table. |
| `significative_data.xlsx` | Filtered subset of `data_results` retaining proteins with p-value < 0.05 (unadjusted). |
| `sig_adjusted_data.xlsx` | Filtered subset of `data_results` retaining proteins with FDR-adjusted p-value < 0.05. |
| `{comparison}_df.xlsx` | One file per pairwise comparison (e.g., `CLN3_KO_vs_WT_df.xlsx`): significant proteins with description, p-value, log₂ fold-change, and Score (log₂FC × −log₁₀(p-value)). |
| `PCA_based_outliers.xlsx` | Sample-level outlier classification based on Hubert robust PCA. Each sample labelled as outlier / non-outlier. See references below. |
| `results_df_enrichGO_ALL.xlsx` | Full results of Gene Ontology over-representation analysis (ORA) via clusterProfiler. Includes fold-change, p-value, gene lists by GO category, and all data needed to reproduce plots. |
| `results_df_gseKEGG_ALL.xlsx` | Full results of KEGG pathway enrichment analysis via clusterProfiler. Includes NES, p-value, gene sets, and supporting data for all comparisons. |
| `results_list_gseGO_ALL.xlsx` | Full results of GO gene set enrichment analysis (GSEA) via clusterProfiler. Includes NES, adjusted p-value, gene sets, and plot data. |
| `STRING_dataframes_name.xlsx` | Gene/protein list submitted to STRING DB for network generation. One entry per comparison. |
| `STRING_plotnames_table.xlsx` | URLs of the interactive STRING network pages generated for each comparison. |

## Figures (`figures/`)

Figures are numbered sequentially from `image_number = 1` (set in the main `.Rmd`).
Numbers below correspond to the example analysis (PXD031582, CLN3 lysosomal interactome);
the sequence is preserved for any new analysis run with the same configuration.

### QC and Normalisation

| # | File suffix | Description |
|---|-------------|-------------|
| 05 | `QC_data_overview` | Bar plots of total protein counts, missing value distribution, and sample-level intensity summaries before normalisation. |
| 06 | `Normalization_diagnosis` | Density plots and boxplots of log₂ LFQ intensities before and after normalisation. Confirms variance stabilisation across samples. |
| 09 | `SD_before_after_scatter` | Scatter of protein SD vs. mean intensity before and after mixed imputation. Assesses whether imputed values inflate variance. |
| 10 | `protein_imputation_distribution` | Density overlay of imputed vs. observed values per condition. Validates that imputed values sit in the low-intensity tail as expected for MNAR data. |

### Dimensionality Reduction

| # | File suffix | Description |
|---|-------------|-------------|
| 14 | `PCA_Splited_Mixed` | PCA biplots for each imputation strategy (MNAR, MAR, mixed), coloured by condition and shaped by replicate. Includes robust PCA outlier overlay. |

### Differential Expression

| # | File suffix | Description |
|---|-------------|-------------|
| 23 | `Heatmap_significant` | Hierarchically clustered heatmap of proteins significant at p < 0.05. Rows: proteins; columns: samples; colour: log₂ intensity Z-score. |
| 26+ | `vulcano_{comparison}` | Volcano plot per pairwise comparison: log₂FC (x) vs. −log₁₀(p-value) (y). Significant proteins coloured and labelled. Thresholds: p < 0.05, \|log₂FC\| > 0.5. One figure per comparison in `comparisons`. |
| 76+ | `Lolliplot_{comparison}_UP/DOWN` | Ranked lollipop chart of up- or down-regulated proteins for each comparison, sorted by Score (log₂FC × −log₁₀(p)). Useful for candidate prioritisation. |

> **Note:** Figure numbers between 14–23 and 26–76 scale with the number of comparisons defined
> in the experiment (one volcano, one heatmap, one barplot set, etc. per comparison).

### Barplots and Fold-Change Correlations

| Plot type | Description |
|-----------|-------------|
| **Barplot** | Significant protein counts per comparison and direction (up/down), split by p-value and adjusted p-value thresholds. |
| **FC correlation scatter** | Pairwise scatter plots of log₂FC values across comparisons. Identifies proteins with consistent or divergent regulation. |

### Functional Enrichment (`figures/enrichGO/`, `figures/gseGO/`, `figures/KEGG/`)

One figure set is generated per comparison and per GO namespace (BP: Biological Process, MF: Molecular Function, CC: Cellular Component):

| Plot type | Description |
|-----------|-------------|
| **Dot plot** | Top enriched terms ranked by gene ratio. Dot size: gene count; colour: adjusted p-value. |
| **Bar plot** | Gene count per enriched term, coloured by adjusted p-value. |
| **Enrichment map** | Network of enriched terms connected by shared genes. Identifies clusters of related biological functions. |
| **GSEA enrichment plot** | Running enrichment score curve for top gene sets (GSEA results only). |
| **Lollipop** | Enriched terms ranked by NES or fold-enrichment, coloured by significance. |
| **KEGG pathway maps** | Pathway diagrams with proteins coloured by regulation direction (up/down). |

### Protein Interaction Networks (`figures/rbioapi/`)

STRING network images are retrieved programmatically via `rbioapi` for each comparison.
Saved as `string_network_image_{n}.png`. Corresponding interactive URLs are stored in
`tables/STRING_plotnames_table.xlsx`.

## RData (`RData/`)

R objects saved at key pipeline stages to enable downstream reuse without re-running
the full analysis:

| File pattern | Contents |
|-------------|----------|
| `prot_data_*.RData` | Cleaned and normalised protein data objects at each processing step |
| `dep_results_*.RData` | limma fit objects and contrast results from differential expression |
| `enrichment_*.RData` | clusterProfiler result objects (enrichGO, gseGO, gseKEGG, gseGO_adj) |
| `stats_*.RData` | Summary statistics objects across all comparisons |

---

## Venn Diagrams (`VennDiagram/`)

Pairwise and multi-way overlap of significant proteins across comparisons. One diagram
per combination. Saved as PDF and TIFF.
